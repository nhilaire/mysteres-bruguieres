# ADR 0001: Expo (CNG) or bare React Native

Status: accepted
Date: 2026-10-28
Decision: expo

> `Decision:` is `expo` or `bare`. `Status:` becomes `accepted` only after the user agrees.

## Context

Mystère à Bruguières is a port of the user's existing Expo SDK 53 app (bare workflow with `expo prebuild`, RN 0.79,
New Architecture on), a geolocated treasure hunt. The PRD (approved 2026-10-28) needs:

- **Location**: foreground GPS watch on radar screens only, permission states (denied / blocked / services off),
  "open settings" and "enable location" actions -> `expo-location` (config plugin, already used by the source, with
  background location disabled).
- **Compass**: native heading (`Location.watchHeadingAsync`) with a magnetometer + accelerometer fallback ->
  `expo-sensors` (its injected ACTIVITY_RECOGNITION permission is blocked, as in the source).
- **Rendering**: an animated radar (rotating sweep, expanding pulse rings, coloured blip, smoothed arrow, arrival
  flash), screen cross-fades, Auguste's breathing portrait and sprite frames, letter flips -> React Native Views +
  `react-native-reanimated` 4 + `react-native-svg` (radar drawn in SVG as in the source, animated props driven by
  Reanimated). Fewer than ~20 animated elements at once: Skia is not needed (and would cost ~10 MB of APK).
- **Audio**: short bundled effects + church bells -> `expo-audio` + `expo-asset` (RECORD_AUDIO blocked).
- **Haptics**: proximity ticks and feedback -> `expo-haptics`.
- **Storage**: progress and settings -> `@react-native-async-storage/async-storage`.
- **Maps link**: `Linking` (React Native core), no library.
- **Firebase**: opt-in Analytics + Crashlytics -> `@react-native-firebase` v26 with its config plugins.
- **Build**: local only on Windows (prebuild + Gradle), APK sideloaded; same flow as the 6 other factory games.

## Criteria

| Criterion | Weight | Expo (CNG + prebuild) | Bare React Native | Notes |
|---|---|---|---|---|
| All required libraries work with Expo prebuild / config plugins | high | yes: every library above is an Expo module or has a config plugin | yes | the source already ran all of them on Expo |
| Need to hand-edit native Android code continuously | high | no | no | permissions and manifest handled by config (`blockedPermissions`) |
| Custom native module (Kotlin/C++) needed | medium | no | no | |
| Upgrade effort over time | medium | low: bump SDK + `expo install --fix` | high: Upgrade Helper native merges | SDK 53 -> 57 bump happens in the port anyway |
| Build simplicity on this machine (local Gradle) | medium | proven (`build-apk.mjs`, 6 games) | proven | |
| Firebase setup effort | low | config plugins | manual Gradle setup | |

## Decision

**Expo (CNG), SDK 57**, with Views + Reanimated 4 + react-native-svg for rendering.

1. Every library the PRD needs is an Expo module or ships a config plugin; the source game already runs them on Expo.
2. No native code to maintain: permission blocking, location strings and Firebase all go through `app.config.js`.
3. Same pipeline as every other factory game (prebuild + local Gradle), the cheapest path to upgrades.

## Consequences

- `android/` is generated by `npx expo prebuild --clean` and git-ignored; native changes go through config plugins.
- The source's SDK 53 code is moved to SDK 57 (RN 0.86, React 19.2): APIs to recheck during the build:
  `expo-location` heading, `expo-sensors`, `expo-audio`, removed `StyleSheet.absoluteFillObject`.
- Radar animations run on the UI thread through Reanimated shared values feeding SVG animated props; the pure
  TypeScript logic (distance, bearing, arrival, pulse interval, puzzle, scoring, navigation) stays testable in Jest.
- Dependencies dropped from the source: `expo-crypto` (no device UUID), `expo-dev-client`, `expo-linear-gradient`
  is kept only if the factory overlay does not already provide gradients.

## Alternatives considered

- **Bare React Native**: no library forces it; it would add native merges at every upgrade for no benefit.
- **Skia canvas for the radar**: more drawing power than needed for a handful of shapes, ~10 MB heavier APK.
